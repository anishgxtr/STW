# Sharda Technical Workshop website

A responsive static website built with HTML, CSS and JavaScript.

## Files
- `index.html` — website content
- `style.css` — layout and styling
- `script.js` — mobile navigation and email enquiry form

## Before publishing
1. Replace the phone number and workshop address in `index.html`.
2. Update `WORKSHOP_EMAIL` in `script.js`.
3. Confirm the services listed on the website match the workshop's actual capabilities.
4. Replace the sample work panels with real workshop photographs if available.

## Publish on GitHub Pages
1. Create a new public repository on GitHub (for example, `sharda-technical-workshop`).
2. Upload all four files to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes; GitHub will show the published website URL in the Pages section.
